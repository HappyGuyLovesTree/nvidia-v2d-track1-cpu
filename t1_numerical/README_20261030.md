# Portable T1 numerical reproduction

Date: 2026-10-30. This directory rebuilds the **numerical** T1 chain from original-format R0 inputs. It does not require a private list of seven deltas or a private accepted-result cache. It does not perform independent human quality review, official stock packing, publication, or competition submission.

The historical production's P13/774 scope, seven statistical proposals and three numerical geometric acceptances are facts about that input. They are not algorithm constants or a claim of quality. This directory is a different source tree and execution interface from the frozen historical A/D producer. Its fixtures do not replace historical outputs or independent acceptance.

## Obtain R0 using the existing baseline source

Use the existing public C2/C3 baseline recipe and its `tools/reproduce.py`, `v2d_public/fresh*`, official input roster and external-assets manifests. Its `assets plan/fetch/unpack`, `inputs pts`, `init`, explicitly authorized `run`, and `export` commands cover official videos/metadata, fixed detector/HMR/rig assets, full original PTS, original controls/raw, six arrays, masks and meshes. Consult that source's `README_PUBLIC_C4_20261017a3.md` and `README_20261017a1.md` for exact acquisition/revision/hash instructions. Weights, videos, raw predictions, identities and original ledgers are not distributed here.

Preserve the baseline numerical producer separately from the portable T1 source identity. Historical C2/C3 artifacts must not be labelled newly inferred by this code. A fresh baseline replay has its own actual producer and is not the historical run.

This adapter takes original `inputs/episode_NNNNNN.json`, `episode_runs/episode_NNNNNN/frame_commits.json`, per-frame controls/HMR, B plans/receipts and budget call slices, plus the matching exported six-array NPZ/mask/OBJ/mesh NPZ. An explicit caller manifest links original numerical run roots to exported artifacts. If a baseline export does not retain those original control/raw/B records, first retain them from the baseline producer; do not fabricate a compatible input manifest or substitute the private accepted deltas.

## Rebuild the scope and statistics

```sh
python portable.py plan --dataset /your/workspace/dataset.json --out /your/workspace/t1-plan
```

The unchanged P planner reconstructs complete segments from original controls, including multiple-high, low, held, unknown, restart, source/frame/PTS/version/size boundaries and the original union-ratio rule. P's returned crop metadata is only a scope-planning artifact: T1 does not run a new crop/HMR or replace pose. The complete scope is generated, not supplied as a private P13 whitelist.

For permitted segments, original current/borrowed status and selected HMR/B start/end parents are checked. Only original `cam_trans` is decompressed from raw NPZ. Seven original points, strict same-segment required consecutive 30Hz, endpoint inheritance, 1.4826 MAD, threshold 3 and epsilon 1e-6 are unchanged. Hash/reference or unclosed-call conflicts stop; they are not ordinary missing windows. Zero MAD, clusters and ambiguous neighbor shape inherit. Statistics are nonrecursive.

Every selected original call has a verified start/end pair. Whole-raw array identities remain opaque because other heads are not decoded; raw bytes/hash are bound by original receipts. Geometry additionally rederives the original adapted rig input from dense q/shape/scales and matches its B call input hash. This is not a new independent audit of every original baseline model output or global unknown budget state.

## Rebuild geometry and new numerical six arrays

```sh
python portable.py run --dataset /your/workspace/dataset.json \
  --out /your/workspace/t1-numerical --rig /your/assets/mhr_model.pt \
  --rig-cap YOUR_EXPLICIT_CAP --execute-models
```

This command is implemented but **was not run on real input/model in this preparation task**. It loads only the fixed rig SHA256 `352e271a6c42729c68554ceaea0c955e866970160c31e35506d782dc0f7377bc`, once, CPU. It generates all proposals again, selects all proposal centers and same-segment ±1 neighbors, derives `reference_count + proposal_count` rig calls and refuses an insufficient explicit cap. There is no new HMR, detector or video decode. No proposals means stop before models; no numerical geometric acceptances means no candidate-array export.

The original geometry functions are byte-identical: add the z increment to the original root, float64 then original storage dtype, only q[2]/t[2], other bits retained; actual rig mesh/22 translation residual <=1e-4m; all actual human vertices/22 and original unpadded object vertices finite, Z>0.05m, exact original-K displacement <=2px. All rejection reasons and trial parameters remain. It neither clips delta nor searches for a passing smaller update.

Native rig plus complete raw forward arrays and canonical call receipts are persistent. `geometry_bundle.json` uses `t1_persisted_geometry_v1`, includes every generated proposal including rejections, parameters with exact q/shape/scales/t/R/scale/K keys, old/new native rig refs, old/new call refs, mesh OBJ/NPZ/consumed identities/transform bindings, baseline/source/model/policy/run identities and affected-edge evidence. `statistical_proposals.json` uses `t1_proposal_index_v1` and binds the newly computed raw proposal file. All counts are data-dependent. Fixture bundles are explicitly marked and cannot establish real inference or acceptance.

The numerical export copies all six arrays and changes only accepted q/t z slots. Static arrays, unselected rows, NaN payloads, masks, OBJ and mesh bytes are checked. The output manifest names every file. Filenames/layout are a numerical export interface, not a claim of completed official stock packaging. The production stock/full-package/independent-quality/public-commit/send gates remain with the separate integration pipeline. This CLI has no submission command and emits `submission_eligible=false`, `quality_pass=false`.

Runtime uses one worker, a <=20-minute explicit cap, 1GiB output/RSS4GiB stops, sampled process-tree RSS/pressure/swap, exclusive output creation and persistent call journals. Failures are retained; no automatic retry/reset. Local public reproduction has its own output budget and source identity; it does not erase, continue or relabel the historical production ledgers.

## Model-free verification and remaining limits

```sh
python -O selftest.py --out /your/workspace/new-fixture-check
```

The test builds entirely synthetic original-format controls/raw/B/dense/mesh/call metadata, then runs the actual CLI under a model/video import firewall. The affine mock checks call shapes, persistent output schema and numerical control flow only. It does not load or simulate MHR accuracy. It repeats from relocated source/data roots, compares complete six-array bits including NaN payloads, and tests count, mesh and parent-hash rejection. No real frame, prediction, identity, video or model is read.

Original-versus-portable core equivalence and file/body mapping are delivered separately to the coordinator. Byte-identical pure bodies do not make this entire directory the historical execution tree. A real fresh baseline-to-T1 replay, the real portable Torch wrapper, independent human/temporal quality, clean dependency installation, full official stock roundtrip and submission are **not verified by these fixtures**. Do not produce a human acceptance receipt from this program's numerical success.
