# T1 persistent-evidence converter and CD-H binding

Date: 2026-10-30. This is an uncommitted integration implementation, tested on synthetic fixtures only. It has not processed real prediction arrays, generated a formal candidate, published source or submitted to Kaggle.

The module consumes fixed R0 outputs and closed A/D artifacts, retains every rejected proposal, verifies persistent rig/native/raw outputs and model input identities, copies all unmodified values bit for bit, assembles the stock view and runs the unchanged official packer. Full conversion performs zero model calls. The old R0 public fresh replay remains documented in the existing README.

The T1 numerical producer is a separate handoff. Until its portable entry and input mapping are integrated and checked, this consumer is **not a complete public R0-to-T1 reproduction**. Do not describe private A/D results as public reproducible inputs. Keep historical C2/C3 producers, actual statistical and D execution trees, the separately ported producer tree, this converter's source digest, and the final build commit as separate identities.

## Private contracts

All runtime paths and data references are injected through private JSON. Do not commit contracts, predictions, complete journals, model weights, private videos, credentials or experiment paths.

`t1_full_contract_v1` identifies the exact sample, required/source plan, baseline episodes/masks/meshes and original HMR/B/rig parent slices; frozen A index and original A reference; persistent D bundle, model and source freeze; independent stage receipts; explicit resource bounds; source freeze and real full Git commit. `artifacts` is an exact list of permitted file refs. Data refs contain canonical absolute `path`, `bytes`, and `sha256`.

Validation follows `prospective_all_A_proposals`, fixed by the a3 adoption. All seven original proposals remain in scope. The original development20 and independent12 remain `proposals=0,status=no_trigger_not_applicable`; they are not replaced with passing update tests. A temporal NA is restricted to this protocol, a bound design artifact, zero eligible edges and complete recorded edges. It does not waive geometry, visible quality, provenance, resource or package gates.

The sealed D schema uses `all_old_reference_rig_outputs` and per-row `mesh_binding`; `native_adapter.py` maps those explicit fields without filtering or relabeling the D producer. A separately frozen `t1_D_adapter_context_v1` binds the D input plan/contract, exact key-id catalog, original parameter snapshots, rational time metadata, source freeze and model ref. The context cannot be inferred by parsing key-id text. Actual field-reference binding still needs the approved real-data integration stage.

Stored q/shape/scales identities differ from actual float32 forward identities. The converter checks both, then checks the full native forward `[1,18439,3]` vertices and `[1,127,8]` joints against the saved canonical arrays. MHR native coordinates become camera metres only by `native * [1,-1,-1] / 100`. Object mesh identity retains the source NPZ dtype; comparison with the original OBJ uses a separate canonical representation. Projection arithmetic follows the D numerical source: `(vertices.astype(float64) * float(scale)) @ R.astype(float64).T + t.astype(float64)`.

## Entry points

Use an existing Python with numpy/pandas/pyarrow for the CLI, psutil for the supervisor, and an explicitly pinned stock Python with trimesh/fast_simplification for the worker/packer. No install or automatic asset fetch occurs.

```text
python tools/t1.py freeze --output <new-private-source-freeze.json>
python tools/t1.py plan --contract <private-full-contract.json> --output <new-header-plan.json>
python tools/t1.py run --contract <private-full-contract.json> --output <new-supervisor-root> --worker-python <pinned-stock-python>
```

`plan` checks only the contract header/executing source and declared counts. It does not validate sample, D arrays, full coverage or candidate readiness. All deep D and prediction-array reads in `run` take place in the live resource-supervised worker; direct official assembly refuses without that worker. `recheck` is a fixture-only convenience, not an official independent acceptance endpoint. Real independent review requires its own authorized supervised process and receipt.

`run` writes a new immutable stock view, provenance, stock stdout/stderr and terminal exit/reap receipt, eight-array roundtrip checks, changed-value counts, full-result evidence and the supervisor journal. Existing output directories refuse reuse. No model import, video decoding or automatic model retry is allowed.

The official send contract is separate and requires a real passed independent package receipt, same-commit public evidence, fresh account/team/day/week metadata, exact recent-submission deduplication, and a read-only snapshot. Fixture results and zero-change outputs cannot send.

```text
python tools/t1.py send --contract <private-authorized-CDH-contract.json> --output <new-binding-directory> --only cd_h_cm
```

The fixed uploader's argv contains only `--track track_1 --only cd_h_cm`. An exclusive intent is written before invoking it; any unknown result requires querying the existing receipt/submissions, never another send. The official uploader's existing explicit rate-limit retry behavior is recorded rather than reimplemented. Remote file-byte identity is not claimed.
