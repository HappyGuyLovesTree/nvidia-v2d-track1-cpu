`--episodes`也支持明确逗号列表；缺输入时明确停止，不静默跳过。首240未通过，其他episode被拒绝。需要真实partial候选时，可对已经完整完成的episode执行aggregate；未完成episode只保留准确的帧/rig检查点，不构造残缺身份/mesh冒充完成。

**恢复命令就是对同一输出根再次执行相同的run命令**，无需删锁或改manifest。所有正常已完成stage被跳过。A未完成时顺序重解码整视频，重新核stream/ordinal/PTS/time_base/尺寸、RGB/blob/HMR输入张量身份，逐帧对照decision/父链并恢复T06后态，已提交的hmr_valid及闭合hmr_failed均不重复forward。B保留完整rig单次调用的暂存安全点；中断在baseline之后可以只执行剩余adapted，不重复baseline。每个新attempt保留父attempt和永久锁文件，活owner拒绝。

**unknown不自动重试，也不从raw猜成功或失败。** 若闭合forward的输出在落盘前丢失，或者模型call_start没有call_end，本次CLI停止该episode并保留调用账，需总控审查后另定处理；不能靠删除日志或换输出目录刷新预算。资源上限触发会锁存停止原因，不能自动重跑来重置额度。合法已提交或持完整闭合证据的孤儿帧可恢复提交。所有预算属于当前run跨episode/attempt累计；本轮只允许一个T08输出根，另开根不会被本工具声称为同一预算。

## 状态、存储与几何

帧终态是原子帧JSON加原子完成索引；临时文件或raw存在不算完成。`frame_committed`区分`hmr_valid`和`hmr_failed`。只有前者要求完整602个float32数、shape/dtype/finite及hash全部通过。异常/错shape/nonfinite且调用闭合的失败帧保存坏raw或异常证据及tracker_after；失败历史不改写。填补另在B计划保存同source父原帧/hash/原因，不计原始成功。本source无有效父就明确失败，不跨gap借父。
